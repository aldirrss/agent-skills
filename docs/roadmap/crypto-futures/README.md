# Roadmap Template — crypto-futures

Template `ROADMAP.md` untuk project crypto futures bot berbasis skills `crypto-futures-*`.

## Cara pakai

1. Copy `ROADMAP.md` ke `docs/ROADMAP.md` di root project kamu
2. Ganti `[PROJECT_NAME]` dengan nama project kamu
3. Tandai item yang sudah selesai dengan `[x]`
4. Tambah atau hapus item sesuai scope project kamu
5. Update Known Technical Debt saat kamu menemukan debt baru

## Isi template

- **Phase 1 MVP** — bot engine + API + dashboard dasar + monitoring + infra
- **Phase 2** — dashboard lengkap (charts, metrics, settings, mobile)
- **Phase 3** — multi-exchange + strategy tuning + backtesting
- **Phase 4** — production hardening (nginx, systemd, backup, auto-recovery)
- Out of scope list
- Known technical debt table
